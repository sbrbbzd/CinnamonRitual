# Notification Modal Usage Walkthrough

## Overview
The new Notification Modal allows users to granularly control their reminder schedules for the Cinnamon Ritual app.

## Features
1.  **Individual Toggles**: 
    - Users can now toggle "Morning", "Afternoon", and "Evening" reminders independently using switch controls.
2.  **Instant Save**:
    - Changes are saved immediately. There is no need to press a "Confirm" button.
3.  **Visual Consistency**:
    - The modal now matches the app's premium "Language Modal" design theme.

## How to Use
1.  Open the App settings or tap the notification/reminder icon.
2.  The modal will appear with three options.
3.  Flip the switch for the desired times.
    - **Morning**: Schedule a reminder for the morning ritual.
    - **Afternoon**: Schedule a reminder for the afternoon.
    - **Evening**: Schedule a reminder for the evening.
4.  To close, simply tap outside the modal content area (on the dark background).
