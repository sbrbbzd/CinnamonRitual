# Onboarding Flow Update Walkthrough

## Overview
The onboarding process has been enhanced to encourage users to set a ritual reminder right from the start.

## User Journey
1.  **Welcome Screen**:
    - The user sees the familiar coffee cup imagery and welcome text.
    - They are prompted to "Enter your name" and "Choose Language".
2.  **Input**:
    - User types their name (e.g., "Sabir").
    - User selects their preferred language (e.g., English).
3.  **Action**:
    - The "BEGIN" button becomes active.
    - Tapping "BEGIN" now **saves the profile** but keeps the user on the screen for one more step.
4.  **Reminder Setup**:
    - A modal appears titled **"SET REMINDER"**.
    - The user can toggle:
        - **Morning**
        - **Afternoon**
        - **Evening**
    - This allows them to immediately schedule their Thursday ritual notifications.
5.  **Completion**:
    - Tapping outside the modal (or if we added a Done button) closes the modal.
    - The app then transitions smoothly to the **Main Screen**, now fully personalized.

## Why this change?
- Increases the likelihood of users setting a reminder, which is critical for the "Thursday Ritual" retention loop.
- Provides a seamless transition from setup to active usage.
